# Decentralized Oracle Adapters

This project aims to provide a modular and extensible framework for integrating various decentralized oracle solutions within smart contracts. It includes adapters for popular oracle networks like Chainlink and Pyth, alongside custom implementations for computed, TWAP (Time-Weighted Average Price), and trusted oracle functionalities. This system is designed to offer flexible and robust external data feeds for DeFi applications and other blockchain protocols.

## Features

*   **Chainlink Adapter**: Integration with Chainlink oracles for a wide range of off-chain data feeds.
*   **Pyth Adapter**: Support for Pyth network's high-frequency, low-latency market data feeds.
*   **TWAP Adapter**: Implementation of Time-Weighted Average Price calculations for robust price feeds.
*   **Computed Oracle**: A framework for defining and executing custom on-chain data computation logic.
*   **Trusted Oracle**: An adapter for integrating data from trusted, centralized sources, with appropriate security considerations.
*   **Modular Design**: Easily extendable architecture to incorporate new oracle providers or custom data sources.

## Installation

To get started with this project, follow these steps:

1.  **Prerequisites**:
    *   [Node.js](https://nodejs.org/) (LTS version recommended)
    *   [npm](https://www.npmjs.com/) (usually comes with Node.js)
    *   A Solidity development environment like [Hardhat](https://hardhat.org/) or [Foundry](https://getfoundry.sh/) is recommended for development and testing.

2.  **Clone the Repository**:

    ```bash
    git clone https://github.com/your-username/decentralized-oracle-adapters.git # Replace with actual repo URL
    cd decentralized-oracle-adapters
    ```

3.  **Install Dependencies**:
    If using a development environment like Hardhat or Foundry, you would typically install their dependencies.

    ```bash
    # Example for Hardhat
    npm install --save-dev hardhat
    npx hardhat compile
    ```
    or
    ```bash
    # Example for Foundry
    forge build
    ```
